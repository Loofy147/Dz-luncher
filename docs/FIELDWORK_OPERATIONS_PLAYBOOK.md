# دليل تشغيل البحث الميداني وضبط الجودة

**الحالة:** إجراء تشغيلي أولي للتجربة المحدودة.  
**الغرض:** توحيد الانتقال من قرار البحث إلى أداة مجمدة، ثم التجنيد والمراجعة والتقرير، دون تحويل الاهتمام المعلن إلى دليل غير مدعوم.

## 1. بوابة تصميم الدراسة

لا تبدأ صياغة الأسئلة قبل ملء سجل قرار مختصر:

- **القرار:** ما القرار الحقيقي الذي سيُتخذ بعد الدراسة؟
- **المالك:** من يملك القرار النهائي ومتى يحتاج النتيجة؟
- **الفئة:** من يواجه المشكلة فعلياً؟ من لا ينطبق عليه التأهيل؟
- **المكان:** الولاية/البلدية أو نطاق الخدمة الذي يمكن الوصول إليه فعلاً.
- **السلوك الحديث:** ما الفترة الزمنية المحددة التي يستطيع المشارك تذكرها؟
- **البدائل:** ما الذي يفعله الناس الآن؟ لا تكتفِ بالسؤال عما يعجبهم.
- **الفرضية:** سؤال واحد قابل للدحض، وقيمة إيجابية محددة وحدّ ونطاق عينة قبل بدء الجمع.
- **القرار المقابل:** ماذا ستغيّر إذا دعمت البيانات الفرضية أو ناقضتها أو بقيت غير حاسمة؟
- **المصدر:** ما قناة التجنيد، ومن قد تستبعده، وكيف سيؤثر ذلك في الاستنتاج؟
- **المخاطر:** هل تتطلب الدراسة بيانات حساسة، أو تتعلق بالصحة أو القُصّر أو التمويل أو الفئات الضعيفة؟ أوقف القالب العام واطلب مراجعة متخصصة قبل المتابعة.

## 2. نص مقابلة اكتشاف احتياج صاحب مشروع

الهدف هو فهم سلوك حديث وقرار فعلي، لا بيع المنصة ولا الحصول على مجاملة.

1. «أخبرني عن آخر مرة احتجت فيها إلى اتخاذ هذا القرار. ما الذي حدث تحديداً؟»
2. «ماذا فعلت أولاً؟ ما البدائل التي جرّبتها فعلياً؟»
3. «ما الوقت أو المال أو الجهد الذي استغرقه الحل الحالي، إن أمكن تقديره؟»
4. «ما الذي لم ينجح؟ كيف عرفت أنه لم ينجح؟»
5. «ما القرار الذي كنت ستتخذه بشكل مختلف لو توفر لك دليل أفضل؟»
6. «ما الدليل الذي سيغيّر قرارك فعلاً؟ وما الدليل الذي لن يكون كافياً؟»
7. «كيف تصل الآن إلى أشخاص يشبهون العملاء الذين تريدهم؟ ومن لن تصل إليه بهذه الطريقة؟»
8. «ما الذي دفعته سابقاً مقابل بحث أو خدمة مشابهة؟» سجّل الإجابة باعتبارها تصريحاً إلى أن تتوفر قرينة مستقلة مصرح بها.
9. «ما الخطوة التالية التي ستنفذها، ومتى؟» اطلب متابعة لاحقة؛ لا تسجّل موافقة لفظية كالتزام شراء.

لا تبدأ بسؤال «هل ستشتري منتجنا؟». لا تملأ إجابة نيابة عن الشخص، ولا تعرض قائمة فوائد قبل توثيق المشكلة والبديل الحالي.

## 3. نص اختبار فهم المشارك

قبل تنفيذ الدراسة، اطلب من شخص غير مشارك في التأليف أن يشرح بكلماته:

- ما هدف الاستبيان؟
- كم يستغرق تقريباً؟
- ما المطلوب منه، وهل توجد مكافأة وما شروطها؟
- ما الذي سيحدث إذا لم يكن مؤهلاً أو احتاجت إجابته إلى مراجعة؟
- كيف يطرح اعتراضاً أو سؤال خصوصية؟
- هل هناك سؤال ملتبس أو خيار إجابة مفقود؟

عدّل السؤال إذا فهمه المختبِر على نحو يختلف عن المقصود. اختبر على هاتف صغير، وباتصال بطيء، وبالعربية RTL قبل النشر.

## 4. خطة التجنيد والسجل

للدراسة التجريبية منخفضة المخاطر، ابدأ بقرار ضيق ومجموعة صغيرة. يمكن استخدام 10–15 مقابلة اكتشاف نوعية ثم 30–50 استجابة استطلاعية عندما يكون ذلك مناسباً؛ هذه أعداد لا تجعل العينة ممثلة وطنياً.

احفظ لكل موجة تجنيد:

| الحقل | ما يجب تسجيله |
|---|---|
| study_id / instrument_version | المعرّف والإصدار الثابت للأسئلة |
| target_segment / geography | الفئة والمكان المحددان قبل الجمع |
| recruitment_source | قناة الوصول ومعرّفها المختصر |
| opened_at / closed_at | فترة الجمع الفعلية |
| target_n / achieved_n | العدد المخطط والمتحقق دون إخفاء النقص |
| quotas | تعريف كل خلية وسبب تحديدها ومصدر تجنيدها |
| policy_version | نسخة سياسة الجودة والمراجعة |
| sample_flow | بدأ، مستبعد بالتأهيل، غير صالح، قيد المراجعة، مقبول، مكتمل الحصة |
| reviewer_reason | سبب قابل للفهم لقرار المراجعة دون تسجيل بيانات غير لازمة |
| appeal_outcome | القرار الأول، الاعتراض، القرار النهائي، والسبب |
| reward_reconciliation | الاستحقاقات والمدفوعات والمراجع الخارجية عند وجودها |
| report_snapshot | نسخة التقرير المرتبطة بالأداة والبيانات المعالجة |

لا تُسجّل أسماء المشاركين في ملف التحليل. افصل أي معلومات لازمة للتواصل أو المكافأة عن إجابات البحث، ولا تجمعها أصلاً إن لم تكن ضرورية ومصرحاً بها.

## 5. Rubric لمراجعة جودة الاستجابة

**الإشارة ليست حكماً.** لا يُرفض الشخص آلياً بسبب إجابة قصيرة أو سرعة واحدة أو جهاز مشترك أو فشل في بند انتباه منفرد.

| محور | ما يراجعه الإنسان | قرار ممكن |
|---|---|---|
| الصلاحية | اكتمال الأسئلة المطلوبة والالتزام بالفروع | قبول أو بيان حقل غير صالح |
| أهلية الدراسة | هل انطبقت معايير التأهيل المعلنة؟ | مطابق أو مستبعد بسبب أهلية |
| الاتساق | تناقض محدد بين إجابتين لهما معنى متعارض | طلب مراجعة أو وضع علامة |
| الجهد | إجابات فارغة/آلية أو نص مكرر بلا معنى في سياق الدراسة | مراجعة لا رفض تلقائي |
| التوقيت | الزمن مقارنة بتعقيد النموذج، لا مقارنة عمياء بوسيط الدفعة | إشارة تدقيق |
| التكرار | محاولة مكررة مؤكدة وفق المعرّفات المسموح بها وسياسة الدراسة | منع الاستحقاق المكرر مع سجل تدقيق |
| النص الحر | هل يحوي معلومات شخصية أو خارج الموضوع؟ | تقليل العرض/الحذف بحسب سياسة معتمدة |
| الضرر المحتمل | احتمال أن تؤدي القاعدة إلى رفض مشروع لمشارك صحيح | تصعيد ومراجعة السياسة |

يسجل المراجع: القرار، السبب المحدد، الوقت، نسخة السياسة، وهل راجع مراجع ثانٍ الحالة. اشرح للمشارك الحالة بلغة عادية، ووفّر مسار اعتراض معقول. لا تكشف تفاصيل تقنية تتيح التحايل على قواعد منع الإساءة.

## 6. سياسة المكافآت والتسوية

- القيمة الافتراضية في القوالب 0 دج؛ لا تعد بمكافأة غير ممولة أو غير معتمدة.
- لا تبدأ حملة مدفوعة قبل اعتماد صياغة الشروط، وتحديد المزوّد والطريقة والأهلية، وتأكيد تمويل كامل الحد الأقصى للحملة خارجياً وفق إجراءات موثقة.
- لا تعتبر سجل دفتر المكافآت وحده دليلاً على أن المال وصل أو صُرف؛ احفظ مرجعاً خارجياً متحققاً منه.
- افصل أموال الحملة عن قرار مراجعة الاستجابة. يجب أن تكون أسباب الحجب والاستئناف مفهومة وقابلة للتدقيق.
- لا تنشئ محفظة داخلية أو رصيداً قابلاً للسحب أو حساب ضمان قبل المراجعة القانونية والتنظيمية وموافقة مزوّد معتمد.
- لكل تسوية مفتوحة: عيّن مالك متابعة، والمبلغ، وعمر الالتزام، وحالة المطابقة، وسبب الفشل، ومحاولة الإعادة التالية.

## 7. إغلاق الدراسة وإعداد التقرير

1. أغلق باب الجمع في الوقت المحدد أو سجّل سبب التمديد.
2. ثبّت إصدار الأداة وقواعد الجودة ومصادر التجنيد.
3. راجع العينة حسب تسلسلها؛ لا تحذف حالات «غير مريحة» بعد رؤية النتيجة.
4. عالج الحالات المعلّقة والاعتراضات وفق سياسة موثقة.
5. طابق التزامات المكافآت مع المراجع الخارجية.
6. اعرض تدفق العينة، والفئات غير المكتملة، والبيانات الناقصة، ومصادر التجنيد والقيود.
7. صنّف كل نتيجة: تفضيل معلن، سلوك مُلاحظ بمصدره، أو معاملة متحققة ومصرح باستخدامها. لا تصعّد نوع الدليل دون مصدر مستقل.
8. اكتب القرار والسبب والخطوة التالية. «الفرضية غير حاسمة» نتيجة صحيحة إذا كانت العينة أو القرينة غير كافية.

## 8. قالب سجل القرار

| الحقل | القيمة التي يجب تعبئتها |
|---|---|
| decision_id | معرّف ثابت |
| question | القرار الذي نحاول حسمه |
| claim_label | ESTABLISHED / EXPERIMENTALLY_SUPPORTED / USER_REPORTED / INFERENCE / HYPOTHESIS / CONTRADICTED / UNKNOWN / OPEN |
| evidence_source | معرّف المصدر أو الاستبيان والإصدار |
| fieldwork_window | تواريخ الجمع ومكانه |
| sample_and_bias | حجم العينة، طريقة التجنيد، وما لا تغطيه |
| result | العدد والمقام والتقدير والنطاق عند الملاءمة |
| competing_explanations | تفسيرات بديلة أو عوامل مربكة |
| decision | استمر / غيّر / أوقف / اختبر مجدداً |
| next_discriminating_test | ما الذي سيغيّر القرار إذا ظهر |
| owner_and_due_date | مالك الإجراء وموعده |
| revalidation_trigger | ما الحدث الذي يستدعي إعادة التحقق |

## 9. بوابات الإطلاق التي تظل مفتوحة

هذا الدليل لا يغلق القضايا التالية تلقائياً:

- مراجعة قانونية جزائرية لنطاق البيانات، والنصوص، والحقوق، والاحتفاظ، وأي نقل عبر الحدود.
- إثبات موضع قاعدة البيانات والنسخ الاحتياطية والدعم والمعالجات الفرعية بعقد موثوق.
- مراجعة الأمن والهوية واستعادة الحساب وتحديد المعدل وإدارة الأسرار والنسخ الاحتياطي والاستعادة.
- قبول مزود الدفع أو الشريك وصلاحية نموذج المكافأة والتسوية.
- تجربة بشرية منخفضة المخاطر مع سجل مراجعة مستقل وقياس الاعتراضات والنتائج الخاطئة.
- مراقبة تشغيلية، ومسؤول عن الحوادث وطلبات البيانات، واتفاقيات دعم واضحة.

حتى إغلاق البوابات، استخدم المكتبة لتحضير المسودات والاختبارات الاصطناعية فقط، لا لجمع بيانات شخصية حقيقية.
